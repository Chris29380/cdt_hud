# Changelog

## 0.1.0

- Configurable player/vehicle HUD, style presets and editable layouts.
- ESX, Qbox and QBCore integration, custom providers and native standalone indicators.
- SQL player profiles, protected server defaults and integration settings.
- Square/round minimap, voice/radio, notifications and cinema mode.
- Seatbelt, configurable collision ejection, cruise control and vehicle indicators.
- Driver-only optional GPS arrival label with distant-terrain fallback, approach height adjustment and diffuse world-space ray.
- Client visibility exports with independent resource/reason requests.
- French/English translations, `cdt_language` server default and player language selection.

Automated tests cover isolated logic. Full gameplay compatibility and performance depend on the installed server, providers and client hardware.

## Français

Première version : HUD personnalisable, frameworks/adaptateurs, profils SQL, minimap, voix/radio, notifications, cinéma, ceinture/éjection, régulateur, clignotants, GPS optionnel, exports de visibilité et traductions français/anglais. Les tests isolés ne remplacent pas la validation en jeu et les mesures de performance sur le serveur cible.
